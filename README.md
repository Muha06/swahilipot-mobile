# SwahiliPot Super App

The SwahiliPot Super App is a mobile application designed to provide a unified platform for accessing SwahiliPot's public content, services, and organizational features.

## Overview

The app will serve both the general public and authenticated SwahiliPot community members, staff, and administrators.

Public users will be able to explore SwahiliPot's content and services without creating an account, while authenticated users will have access to additional functionality based on their role.

## User Roles

### Public User

- View About SwahiliPot
- View organization information
- View social media
- View events
- View programs
- View features/services
- Listen to SwahiliPot FM/Radio

### Community Member

- All Public User abilities
- Access community-member features

### Staff

- All Public User abilities
- Access staff features
- Staff messaging _(optional/future)_

### Admin

- All Public User abilities
- Create and manage posts
- Create and manage programs
- Manage organizational content
- Access administrative features

## Main Features

- About SwahiliPot
- Organization information
- Social media
- Events
- Programs
- Features / Services
- SwahiliPot FM / Radio
- Authentication
- Role-based features
- Content management

## Authentication

Eligible Community Members and Staff will be able to create accounts using a SwahiliPot organizational email.

Authentication will include:

- Registration
- Login
- Email verification
- Password recovery
- Logout
