# SwahiliPot Super App — Development Plan

## 1. Project Overview

The SwahiliPot Super App will provide a single mobile platform for accessing SwahiliPot's public content and services, while providing additional functionality for authenticated community members, staff, and administrators.

---

## 2. User Roles & Abilities

### Public User

- View About SwahiliPot
- View organization information
- View social media
- View events
- View programs
- View features/services
- Listen to SwahiliPot FM/Radio

### Community Member

- All Public User abilities
- Access community-member features *(TBD)*

### Staff

- All Public User abilities
- Access staff features
- Staff messaging *(optional/future)*

### Admin

- All Public User abilities
- Create and manage posts
- Create and manage programs
- Manage other organizational content
- Access administrative features

---

## 3. Authentication

Authentication will be available to eligible Community Members and Staff using a SwahiliPot organizational email.

- Registration
- Login
- Email verification
- Password recovery
- Logout
